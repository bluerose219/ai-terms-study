# AI 용어 사전 (ai-terms-study)

YOLO로 안전모·불꽃 탐지 모델을 학습할 때 필요한 AI 용어와 평가지표를 정리한 학습용 페이지입니다.

- 웹페이지: https://bluerose219.github.io/ai-terms-study/
- 내용: 데이터·학습·하이퍼파라미터·결과 파일·프레임워크와 ONNX·양자화·평가지표(정밀도, 재현율, F1, 특이도, ROC/AUC, IoU, mAP)
- 정밀도·재현율·F1 계산기와 확인 문제 포함

단일 HTML 파일(`index.html`)로 되어 있어 브라우저에서 바로 열 수 있습니다.
